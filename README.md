# 🎵 Music Player

A sleek, modern, dark-themed web music player built with **HTML, CSS, and JavaScript**.
It features a beautiful glassmorphism-style UI, animated gradient background, and a curated playlist experience with playback controls.

## 🌐 Live Demo

👉 **GitHub Pages:** [https://onkarjadhav5598.github.io/Music-Player/](https://onkarjadhav5598.github.io/Music-Player/)

## ✨ Features

- 🎧 Play / Pause music
- ⏮ Previous track / ⏭ Next track controls
- 📀 Dynamic album cover, song title, and artist updates
- ⏱ Real-time current time and total duration display
- 🎚 Seek bar for scrubbing through tracks
- 🔊 Volume control + mute/unmute toggle
- 🌈 Animated dark gradient background
- 📱 Responsive layout for smaller screens

## 🛠 Tech Stack

- **HTML5**
- **CSS3**
- **Vanilla JavaScript**

## 📂 Project Structure

- `index.html` — Player layout and styling
- `app.js` — Playlist data and player logic (audio controls, seek, volume, track navigation)
- `README.md` — Project documentation

## 🚀 Getting Started

You can run this project locally in a few seconds:

1. Clone the repository
   ```bash
   git clone https://github.com/onkarjadhav5598/Music-Player.git
   ```
2. Go to the project folder
   ```bash
   cd Music-Player
   ```
3. Open `index.html` in your browser

That’s it — no build tools or dependencies required.
